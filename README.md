# Ayma

AI matchmaking platform — Flutter client, Cloud Run backend, PostgreSQL, Gemini Live voice.

**Start here:** [`PLAN.md`](PLAN.md) (execution checklist) → [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) (full system design).

## Quick commands

```bash
cd ayma_flutter && flutter run          # mobile app
cd ayma_flutter && flutter analyze      # static analysis
python3 -m unittest functions/bootstrap/test_main_logic.py   # backend tests
```

See [`docs/agent.md`](docs/agent.md) for deploy, device setup, and env vars.
