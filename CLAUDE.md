# Coding Agent Guide

**Start here: read `docs/agent.md` before touching any code.** It has the full project state, active work, architecture rules, and deploy commands. Everything else in this file is a supplement.

---

## Quick Reference

| Task | Command |
|---|---|
| Run app | `cd ayma_flutter && flutter run` |
| Check for issues | `cd ayma_flutter && flutter analyze` |
| Deploy Cloud Run | see `docs/agent.md` → Deploy Commands |
| Deploy Firestore rules | `firebase deploy --only firestore:rules` |

## Coding Rules

- `flutter analyze` must stay at 0 errors, 0 warnings — check before reporting any task done
- All Firestore reads/writes go through `FirestoreService` — no scattered `FirebaseFirestore.instance` calls in screens
- No comments unless the WHY is non-obvious
- Do not edit `firebase_options.dart` manually — it is generated by `flutterfire configure`
- After any code change, update `docs/agent.md` (active work checkboxes) and `docs/ARCHITECTURE.md` if the system design changed
